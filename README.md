# こんだてラボ

小学校5・6年 家庭科「理想のこんだてづくり」の単一HTMLアプリ。

公開ページ： https://tt-sensei.github.io/kondate-lab/

## 概要
- 主食・主菜・副菜・汁ものをタップで選ぶと、お膳に自動で配膳される（左手前に主食、右手前に汁もの、右奥に主菜、左奥に副菜）
- 3色食品群（黄★・赤●・緑■）の「はたらきポイント」（各料理0〜3点）を棒グラフで表示し、バランス判定と改善ヒントを出す
- 「ちょい足し食材」（最大3つ）で不足を補う試行錯誤ができる
- 「おまかせ ランダム」でランダムな献立を出し、それをよりよく直す遊び方ができる
- 調理法の重なり（揚げ物×2）、いも類の重なりも判定
- アレルギー表示は2026年4月改正の29品目（義務9・推奨20）に対応する形で、選んだ料理のアレルゲンを一覧表示
- 色はカラーユニバーサルデザイン推奨配色＋記号・ラベル併記
- ナビキャラ「さく」のガイド付き（表情とひとことが状況で変わる）
- 音ON/OFF（端末に保存）、献立はlocalStorageに自動保存
- 外部API・外部フォント・CDN不使用（共通基盤の edu-effects / sounds-recipe- / ナビキャラ画像のみ、従来アプリと同じ扱い）
