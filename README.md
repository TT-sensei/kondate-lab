# こんだてデザイン

小学校6年生の家庭科「栄養バランスを考えた1食分のこんだてづくり」を想定した、単一HTMLの学習アプリです。

公開ページ： https://tt-sensei.github.io/kondate-lab/

## 学習の流れ

1. 主食・主菜・副菜・汁ものを選び、お膳に並べる
2. 食材や調理法の組み合わせを考えて献立をつくる
3. 「結果を確認！」を押して、3色食品群のはたらきバランスと改善のヒントを確認する
4. 料理を入れ替え、よりよい献立に改善して再評価する

料理を選んでいる間は、ポイントや評価を表示しません。料理カードにも数値を表示せず、子ども自身の見通しや判断を大切にします。

## 主な機能

- 主食11品・主菜12品・副菜12品・汁もの10品の計45品から選択
- ちょい足し食材12品（最大3つ）
- 「バランスこんだてチャレンジ」モード
  - 主食・主菜・副菜・汁ものをそろえる
  - 黄・赤・緑のはたらきポイントをそれぞれ3〜6にする
  - 揚げ物やいも料理の重なりを避ける
  - 調理法を2種類以上組み合わせる
- 評価後に3色のポイント、達成状況、改善ヒントを表示
- おまかせランダムで献立をつくり、改善する活動
- 調理法・登録メニューの主なアレルゲン情報を表示
- 料理の選択状態をlocalStorageに保存
- ナビキャラ「さく」のガイド、効果音ON/OFF
- タブレットを想定した1画面レイアウト。料理一覧は必要に応じて内部スクロール

## 学習上の注意

3色のポイントは、料理に含まれる食品のはたらきを考えるための学習用モデルです。実際の栄養量や1日に必要な量を示すものではありません。

アレルゲン情報は登録した料理例の情報です。実際の調理では、使う材料や商品によって異なるため、原材料表示や学校・家庭の確認方法に従ってください。

## 技術・保存

- 単一HTML構成
- 外部API・外部フォント・CDN不使用
- 共通基盤の edu-effects、効果音、ナビキャラ画像を利用
- 保存キー：`kondateLab.menu.v1` / `kondateLab.settings.v1`
